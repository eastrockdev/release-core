# ReleaseCore M17.1 — Release Templates & Duplication

M17.1 begins the M17 Catalog Operations roadmap.

## Reusable release blueprint

ReleaseCore can now turn an existing release into a sanitized reusable blueprint.
A blueprint carries forward:

- release format;
- primary genre;
- release-level artist assignments;
- track structure/order;
- track title/version/language/explicit flag;
- track artist assignments;
- contributor credits and publishing percentages;
- availability mode;
- pre-order enablement and preview policy;
- release-time policy;
- synchronous unlocking;
- exclusive-window partner and duration.

## Reset policy

A duplicated or template-created release is always a new draft. ReleaseCore does
not carry forward release-specific identifiers or operational state:

- release date;
- pre-order date;
- pre-save URL;
- streaming URL;
- UPC;
- catalog number;
- existing ISRCs;
- master/supporting files;
- artwork/files;
- Shopify product IDs/handles;
- submission/review history;
- distribution state;
- ownerCustomerId / customer ownership.

When ReleaseCore ISRC automation is enabled, new track records go through the
normal `maybeAutoAssignIsrc` path and therefore receive fresh identifiers rather
than copying source ISRCs.

## Release Templates

Settings → Release Templates stores reusable blueprint snapshots in
`ReleaseTemplate`.

Templates are local ReleaseCore data and remain valid even if the source release
later changes. Editing a source release does not silently mutate a saved
template.

## Duplicate Release

Every release workspace now exposes **Duplicate release**.

The flow opens Create Release with the source selected. The user can rename the
new release before creation. The source record is never changed.

## Save as Template

Every release workspace also exposes **Save as template**, which opens the
Release Templates workspace with that release selected as the source.

## New Release

Create Release now supports three modes:

1. blank release;
2. saved template;
3. duplicate a specifically selected existing release.

Template and duplicate formats are inherited from the reusable blueprint so a
Single cannot accidentally become a multi-track release.

## Shopify / distribution safety

M17.1 does not copy Shopify product relationships and performs no Shopify API
calls. New drafts enter `DRAFT` / `NOT_QUEUED` and must pass the normal
ReleaseCore submission and distribution workflows.
