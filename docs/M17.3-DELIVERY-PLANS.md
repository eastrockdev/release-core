# ReleaseCore M17.3 — Advanced Store & Territory Availability

M17.3 moves platform and territory decisions into a dedicated Distribution
Delivery Plan.

## Release-wide platform modes

A release can target:

- All current & future platforms
- Include only selected platforms
- All except selected platforms
- Social platforms only

The platform registry distinguishes normal DSP/music-service delivery from
social delivery.

## Territory modes

Release-wide territory availability supports:

- Worldwide
- Only selected territories
- Worldwide except selected territories

ReleaseCore stores ISO 3166-1 alpha-2 territory codes. The UI includes the full
ISO country/territory list.

## Platform exceptions

Each platform can override the release-wide plan with:

- inherited / forced enabled / forced disabled state;
- store-specific release date;
- inherited / worldwide / include / exclude territory mode;
- platform-specific territory list;
- operational note.

This allows a release to stay worldwide and all-platform by default while still
expressing exceptions cleanly.

## Exclusivity windows

A delivery plan can select one exclusive platform with start and end dates.

ReleaseCore's effective plan calculation marks other included platforms as held
until the exclusivity window ends unless their own configured release date is
later.

The legacy Release availability/exclusivity fields are synchronized for
backward compatibility, but M17.3's Delivery Plan is the richer operational
source for future distributor export.

## Distribution workspace

Every release's Distribution workspace now exposes **Delivery plan** as a
secondary action.

The dedicated route is:

`/app/distribution/:releaseId/delivery-plan`

No Shopify publication mutation occurs from this page.

## Audit

ReleaseCore records:

- `DELIVERY_PLAN_UPDATED`
- `DELIVERY_CHANNEL_UPDATED`
- `DELIVERY_CHANNEL_REMOVED`

as SubmissionEvent history.

## Future boundary

`serializeDeliveryPlanForExport()` provides a normalized local representation
that M17.7 Delivery Package / Distributor Export can consume later without
coupling the delivery-plan UI to any one distributor.
