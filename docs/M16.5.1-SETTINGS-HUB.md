# ReleaseCore M16.5.1 — Focused Navigation + Settings Hub

This usability follow-up keeps ReleaseCore's primary navigation centered on frequent production work.

## Primary sidebar

The embedded Admin sidebar now contains only:

- Home
- Operations
- Releases
- Submissions
- Distribution
- Artists
- Settings

Submission and Distribution attention badges remain.

## Settings hub

`/app/settings` becomes a traditional card-based application settings hub.

Lower-traffic tools are grouped into:

### Release workflow
- Release preferences
- Import catalog
- Contributors

### Artists & customer access
- Portal access
- Storefront setup
- Purchases & downloads

### Automation & communication
- Automation
- Notifications

### System & support
- System issues
- Feedback
- Privacy

## Existing preferences

The large existing ReleaseCore settings editor is preserved intact at:

`/app/settings/preferences`

The route is now labeled **Release Preferences**.

This preserves all submission, identifier, pricing, Shopify product, audio preview, and customer download settings without forcing them to compete with every other app destination in the sidebar.

## Efficiency

The app shell no longer queries the open System Issue count merely to decorate a low-traffic sidebar item.

System Issue counts remain available in Operations where they are operationally meaningful.

The app shell also no longer maintains current-location state solely for a global Feedback link.

## Compatibility

M16.4 and M16.5 validators are evolved so they verify that System Issues and Feedback remain discoverable through the Settings hub / Operations experience rather than requiring them to remain top-level sidebar items.

No Prisma migration, Shopify scope, webhook, extension, or TOML change is included.
