# ReleaseCore M16.9 — Operational Metrics

M16.9 is the final M16 milestone. It adds an on-demand operational telemetry
workspace without introducing a new analytics provider or instrumenting every
request with additional writes.

## Data sources

Operational Metrics is calculated from durable ReleaseCore records that already
exist for workflow correctness:

- `Release`
- `OperationJob`
- `SystemIssue`
- `SubmissionEvent`
- `NotificationDelivery`
- `ProductionMutation`
- `DataMaintenanceEvent`

The metrics loader does not call Shopify.

## Windows

The page supports:

- 7 days
- 30 days
- 90 days

7- and 30-day charts use daily buckets. 90-day charts use seven-day buckets.

## Release throughput

The page reports releases that were:

- created;
- submitted/resubmitted based on `lastSubmittedAt`;
- currently approved with a decision in the window;
- currently delivered with a distribution-state update in the window.

These are operational throughput indicators, not royalty or consumption
analytics.

## Background-job reliability

Metrics include:

- jobs created;
- succeeded / failed;
- completion success rate;
- retry attempts beyond the first attempt;
- current queued/running counts;
- oldest queued job age;
- median and p95 queue wait;
- median and p95 runtime;
- bounded success/failure trend.

Exact counts are independent from the bounded latency/trend sample.

## Shopify sync reliability

M16.9 reuses the same SubmissionEvent sync signals already consumed by the
Operations Center:

Success:
- `SHOPIFY_PRODUCTS_SYNCED`
- `SHOPIFY_RELEASE_PRODUCT_SYNCED`
- `SHOPIFY_SYNC_RETRY_SUCCEEDED`

Warning:
- `SHOPIFY_SYNC_WARNING`
- `SHOPIFY_PUBLICATION_WARNING`

Failure:
- `SHOPIFY_SYNC_FAILED`

Exact counts remain complete even if trend rendering reaches its bounded sample.

## Diagnostics

The workspace reports:

- current open System Issues;
- new issue fingerprints in the selected window;
- issue fingerprints touched in the window;
- critical/error fingerprints;
- most frequent issue operations;
- notification failures;
- audited Data Maintenance actions;
- M16.8 protected mutation counts and top operations.

## Performance

The page is on-demand and runs local PostgreSQL queries in parallel. M16.9 adds
indexes for metric time-window access paths on Release, OperationJob,
SystemIssue, SubmissionEvent, and NotificationDelivery.

No Shopify API request is required to render metrics.
